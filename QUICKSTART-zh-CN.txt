RenderMesh 0.3.0 — Windows x64 快速指南
=======================================

用途
把 Blender 动画分给局域网内的空闲电脑渲染，再收回图像。
每台电脑都能提交任务，也能提供算力。无需中心服务器。

项目：https://github.com/FELIXDAD/RenderMesh
完整指南：https://github.com/FELIXDAD/RenderMesh/blob/main/docs/USER_GUIDE.md
命令行：https://github.com/FELIXDAD/RenderMesh/blob/main/docs/CLI.md

1. 启动
-------
解压 ZIP 到固定、可写的目录，双击 RenderMesh.exe。
RenderMesh 本身不需要 Python 或 .NET。
渲染需要单独安装 Blender；提交电脑和工作电脑使用相同主、次版本。
在设置页检查 Blender 路径。自定义位置可用“手动指定…”选择。
也可用“安装 / 切换 Blender 版本”下载官方 MSI。
EXE 未做商业代码签名，Windows 可能提示未知发布者。

2. 连接电脑
-----------
给各台电脑输入相同的六位匹配 ID。
在提供算力的电脑开启“共享本机算力”。
等待电脑达到空闲阈值，默认 180 秒。
自动发现失败时，手动输入对方 IPv4:8391。
127.0.0.1 只表示当前电脑。
默认端口为 UDP 8390 和 TCP 8391，只用于可信局域网。
不要把端口映射到互联网。

3. 准备工程
-----------
在 Blender 保存 .blend，设置帧范围、引擎、逐帧图像格式和输出目录。
检查素材路径。工程同级的 tex 文件夹会随工程传输。
建议使用 //tex/... 相对路径。
插件、模拟缓存和无法打包的外部文件需要在工作电脑准备一致的环境。
“无视警告”不会补齐缺失素材。

4. 提交和渲染
-------------
在“渲染任务”页拖入 .blend 或使用添加按钮。
等待工程读取、检查、创建任务和同步完成。
选择软件配置、帧范围、步长、每包帧数和测试帧。
每包 1–20 帧，默认 5。
先完成测试帧并检查图像。
显示“测试完成”后，右键任务选择“全速渲染”。
提交电脑负责调度和收集，渲染期间保持运行。
没有可用远端电脑时可以使用本机。

5. 任务与输出
-------------
任务详情显示每帧状态、电脑、时长、日志和错误。
主图与 File Output 输出写回提交电脑的对应目录。
停止会保留已完成帧；正在渲染的当前帧完成后停止后续帧。
“恢复渲染”继续已停止帧，“重试”重新处理失败帧。
“编辑渲染主机”可增减参与电脑，新节点先同步工程。
删除任务会清理托管副本，保留源工程及工程输出目录中的成品。
重新渲染相同输出路径可能替换已有结果。

6. 设置与更新
-------------
配置、日志和任务记录默认在 %LOCALAPPDATA%\RenderMesh。
工程存储可在设置页改到空目录；程序复制并校验后切换。
config.json 含凭证，不要公开上传。
关闭行为可设为退出或最小化到通知区域。
开机自启和静默自启可在设置页启用。
更新前停止任务并退出程序，替换 EXE，保留数据目录。
同组电脑也可通过已认证节点接收局域网更新提示。

7. 命令行（PowerShell）
----------------------
.\RenderMesh.exe help | Out-Host
.\RenderMesh.exe status --json | Out-Host
.\RenderMesh.exe inspect "D:\Projects\shot.blend" --json | Out-Host
.\RenderMesh.exe submit "D:\Projects\shot.blend" --wait --json | Out-Host

任务命令需要桌面程序或 serve 正在运行。
submit 只创建和同步任务；使用 test 测试后再 start。
退出码：0 成功；1 操作失败；2 参数错误；3 无法连接本机节点。
