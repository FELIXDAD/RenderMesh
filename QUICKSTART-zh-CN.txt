RenderMesh 0.3.0（Windows x64）

无需安装、无需 Python、无需 .NET、无需管理员权限。

1. 解压整个 ZIP，双击 RenderMesh.exe。
2. 第一次 Windows 网络提示只允许“专用网络/域网络”。
3. 程序会自动查找标准安装目录、PATH 或解压目录 Blender\blender.exe。未找到 Blender 时会弹出内部提醒：可实时读取 Blender 官方镜像的近期 Windows MSI，选择带 LTS 标记的版本或普通版本、指定 MSI 下载目录，并在官方 SHA-256 校验通过后打开 Windows 安装程序。设置页“安装 / 切换 Blender 版本”可随时重新打开版本选择器；自定义安装位置可在设置页“Blender 路径 → 手动指定…”中直接选择 blender.exe。未安装 Blender 的电脑仍显示在线，但不会同步工程或接受任务。
4. 所有电脑输入相同的六位匹配 ID；同一局域网内无需预先填写 IP，每台电脑都会通过定向广播和局域网组播直接发现其他电脑并独立验证。没有中心服务器，也不依赖最先启动或用于测试的电脑持续在线。两端 ID 不同绝不会连接。
5. 愿意提供算力的电脑打开左上角“共享本机算力”开关，按钮会明确显示“已开启”。
6. 若公司网络同时禁用了 UDP 广播和局域网组播，才需要在“手动连接”填写任意一台在线电脑“本机”行显示的局域网 IP:8391；不要使用 127.0.0.1。认证目录只补充候选 IP，在线与任务状态仍直接从对应电脑读取。
7. 进入“渲染任务”，直接拖入 .blend，或点击右下角添加按钮选择工程。全窗口加载面板会依次显示“读取并检查工程、创建任务”两个步骤，期间阻止重复操作；本地预检通过后，上传窗口会显示每台参与电脑的断点续传进度；全部就绪后才可点击“下一步”。
8. 在参数窗口确认软件配置和自动读取的帧范围，设置每包帧数（1–20，默认 5）和测试帧，例如 1,4,6-10,30-35。在线节点优先，没有节点时由本机渲染；状态变为“测试完成”后，可点击任务详情右下角绿色播放按钮，或在任务列表右键选择“全速渲染”，才会执行其余帧。正式渲染时该位置会改为红色停止按钮。已停止的任务可在任务列表右键选择“恢复渲染”：已完成帧保持不变，仅把已停止帧重新排队。Ctrl/Shift 多选任务可批量全速渲染或删除。输出格式和路径完全使用工程设置。

C 盘空间有限时，进入“设置 → 工程存储 → 更改位置…”，选择其他磁盘上的空文件夹。RenderMesh 会暂停节点服务，在后台复制并校验现有任务工程和缓存，完成后自动切换并清理旧目录；取消或失败时继续使用原目录。

任务详情可查看每帧状态/时间、预览图像、定位源工程与输出；任务包已接收但尚未轮到的帧显示“排队中”，时长保持为“-”。只有 Blender 真正开始当前帧后才显示“渲染中”并开始计时，每帧时长来自 Blender 为该帧单独记录的真实起止时间，不会把同包前面帧累计进去。双击任意单帧可打开 Blender 日志详情，渲染中会增量刷新，完成、失败或停止后保留最终日志。OpenEXR 等 Windows 无原生解码器的格式会由已安装的 Blender 生成预览。“本机贡献”会保留这台电脑替别人渲染过的任务包历史，可多选后清理所选记录。
0.2.28 起，精确的远端单帧开始状态使用协议 v15。新发起端遇到尚未声明该能力的旧 Worker 时会自动降为单帧包，避免五帧都长期显示“排队中”；要获得准确的实时开始时间，并确保在 Blender 打开工程阶段点击停止可立即释放节点，请把参与渲染的电脑都更新到同一版本。

每个任务都可右键选择“编辑渲染主机”。窗口会同时列出原参与者和后来新加入的在线电脑，支持 Ctrl/Shift 多选、全选和反选；选中电脑后使用“加入”或“断开”，也可在选中行上右键执行相同操作。加入的电脑先续传工程再接单，断开的电脑不再收到后续任务包。
如果 .blend 同级存在 tex 文件夹，0.2.29 会把它和工程一起缓存到 Worker，并保持 tex 下的相对目录。带 tex 的任务只允许选择 0.2.29 或更高版本节点；不含 tex 的任务仍兼容现有节点。
0.2.29 是自动更新基线。0.3.0 大幅缩短大型工程导入：每次只打开一次工程，只打包 tex 文件夹之外确实需要打包的素材，没有需要打包的内容时不再另存副本，tex 文件夹直接从原文件写入工程包；程序体积约减少一半，并新增命令行（见下文）。首次启动 0.3.0 会自动导入旧版任务记录。0.2.44 在设置页增加手动指定 blender.exe 入口，选择后立即更新当前渲染软件配置和节点可用状态。0.2.43 可在设置中更改全局工程存储目录；更改时后台复制并校验任务工程、远端缓存、上传临时文件和预检中间文件，原子切换后再清理旧目录。配置、日志、更新器和小型数据库仍保留在本机配置目录。程序每次启动只自动检查一次。
点击关闭按钮可选择直接关闭或最小化到任务托盘，并可记住选择；也可在设置的“当点击关闭时”中修改。托盘图标使用简化 RenderMesh 网格主体和 Fluent 状态角标：绿色勾表示空闲、紫色同步箭头表示渲染、红色感叹号表示错误；单击恢复窗口，右键可查看进度、切换共享或退出。
设置页可开启“开机自动启动”；开启后才可选择“自启时静默运行”。静默模式仅对 Windows 开机自动启动生效，程序直接驻留托盘且不弹出主界面；手动双击 RenderMesh.exe 会恢复同一个后台实例，不会重复启动或占用第二个端口。关闭开机自动启动会同时关闭并禁用静默选项。
两个启动开关使用无整行底框的紧凑样式；把鼠标移到静默启动后的信息图标可查看说明。设置页同时显示当前版本；手动检查没有发现更高版本时，会用 RenderMesh 内部提示窗显示“当前已是最新版本”。

预检会自动检查并打包外部素材，同时记录 Blender 主/次版本和渲染引擎。
合成器 File Output 节点（含 Blender 5.2 AOV/多层 EXR 输出项）会一起记录；每帧完成后立即从 Worker 回传到工程设置的原目录。若工程文件名模式没有帧号，RenderMesh 会补六位帧号，避免任务包内多帧互相覆盖。
发起端预检不会渲染提交范围内的任何帧；实际出图兼容性由随后只在参与 Worker 上运行的测试帧确认，因此大帧段不会在导入时被本机逐帧执行。
缺失素材、无法打包、插件或节点问题会先提醒并列出可用信息。选择“无视警告”后会跳过全部预检警告，直接准备工程并进入上传/参数设置，最终渲染结果由用户决定；仅源工程无法读取或复制时不能继续。插件安装、启用和版本清单不再比较；依赖第三方插件的工程建议先提交少量测试帧验收。
如果远端 Blender 在启动后立即正常退出却没有生成任何帧，Worker 会自动重启该任务包一次；再次失败会把明确错误和 Blender 日志回传到任务详情。
首次安装或升级 Blender 后，RenderMesh 会先在后台完成一次无界面初始化；仅在偏好文件不存在时生成默认配置，15 秒未完成会终止进程并报告错误。Cycles GPU 会在每个进程内选择一个可用后端，不覆盖已有偏好。
提交时若 Blender、Windows Defender、同步软件或索引器短暂占用刚打包的工程，RenderMesh 会自动等待并重试，不会因一次共享冲突直接丢弃任务；持续占用或真实权限错误仍会明确提示。

命令行（供脚本和 Claude、Codex 等智能体使用，帮助为 ASD-STE100 简化技术英语）：
  RenderMesh.exe help                       显示全部命令
  RenderMesh.exe help submit                显示一个命令的选项
  RenderMesh.exe inspect 工程.blend --json   只检查工程，不创建任务
  RenderMesh.exe submit 工程.blend --wait    检查工程、创建任务并等待同步完成
  RenderMesh.exe test <任务ID> --test-frames 1,50,100
  RenderMesh.exe start|stop|resume|retry|delete <任务ID>
  RenderMesh.exe status | jobs | job <任务ID>
  RenderMesh.exe serve                      无窗口节点，Ctrl+C 停止
除 inspect 外，任务命令需要本机已打开 RenderMesh 或正在运行 serve。退出码：0 成功，1 失败，2 命令或参数错误，3 本机没有运行 RenderMesh。加 --json 输出单行 JSON。
在 PowerShell 中可用 "RenderMesh.exe status | Out-Host" 等待输出；在 cmd.exe 中可用 "start /wait RenderMesh.exe status"。

默认策略：
- 共享算力：关闭
- 所有远端渲染：连续 180 秒无键鼠输入后才接单，键鼠恢复后完成当前帧，其余帧停止并重派
- Eevee：Worker 必须同时具备可用 Eevee 引擎和 Windows GPU 图形设备，否则拒绝任务
- Cycles GPU：Worker 必须检测到已启用的非 CPU Cycles 设备，否则拒绝任务
- 不使用 CPU 限速；电脑活跃时不接受任何远端渲染任务

数据和结果：%LOCALAPPDATA%\RenderMesh
端口：UDP 8390（发现），TCP 8391（任务/结果）

注意：只用于可信公司内网，不要暴露到互联网。选择“直接关闭”或从托盘退出后本机才会离线；最小化到托盘时节点继续运行。
